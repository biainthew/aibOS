### Cron 이란 ?


리눅스나 유닉스 계열 운영체제에서 특정 시간에 특정 작업을 자동으로 실행해 주는 시간 기반 잡 스케줄러


크론을 통해 자동으로 실행되는 작업을 크론 잡이라고 함


### 사용 방법


설정할 때는 crontab 이라는 설정 파일을 사용하는데 이 파일에 언제 어떤 명령어를 실행할지 규칙을 적어둠


{% raw %}
```javascript
*   *   *   *   * 실행할_명령어
┬   ┬   ┬   ┬   ┬
│   │   │   │   └─ 요일 (0 - 7) (0과 7은 일요일, 1은 월요일...)
│   │   │   └─ 월 (1 - 12)
│   │   └─ 일 (1 - 31)
│   └─ 시 (0 - 23)
└─ 분 (0 - 59)
```
{% endraw %}


**자주 쓰는 예시**


| **설정 코드**                | **의미**                          |
| ------------------------ | ------------------------------- |
| `0 0 * * * /backup.sh`   | 매일 자정(00:00)에 `backup.sh` 실행    |
| `*/10 * * * * /check.sh` | 10분마다 `check.sh` 실행             |
| `0 9 * * 1 /report.sh`   | 매주 월요일 오전 9시 0분에 `report.sh` 실행 |
| `30 22 1 * * /month.sh`  | 매월 1일 밤 10시 30분에 `month.sh` 실행  |


### 언제 사용하는지 ?

- 매일 새벽 서버 데이터를 백업할 때
- 주기적으로 임시 파일이나 로그를 삭제해야할 때
- 매달 정해진 날짜에 사용자에게 알림이나 메일을 발송할 때
- 일정 시간마다 외부 API 에서 최신 데이터를 긁어와 업데이트할 때
