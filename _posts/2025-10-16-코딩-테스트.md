### ✔️ 정답 코드


{% raw %}
```javascript
function solution(n) {
    let result = [];
    let divisor = 2;

    while (n>=2) {
        if(n % divisor === 0){
            result.push(divisor)
            n = n / divisor
        }
        else divisor ++;
    }
    return [... new Set(result)]
}
```
{% endraw %}


### 🐥 해설


{% raw %}
```javascript
function solution(n) {
    let result = [];
		//정답을 넣을 빈 배열
    let divisor = 2;
		//초깃값

    while (n>=2) {
        if(n % divisor === 0){
            result.push(divisor)
            n = n / divisor
						//배수를 제거하기 위해서
        }
        else divisor ++;
    }
    return [... new Set(result)]
		//중복제거
}
```
{% endraw %}


### Set


: value 값만을 저장하며 중복을 허용하지 않음


: value 값으로 같은 객체가 들어올 경우에는 중복값으로 인지하지 않음


: 대소문자 구분


: value 값으로 고유한 값을 가질 수 있고 **중복값 제거**가 가능하기 때문에 사용


{% raw %}
```javascript
const empty = new Set();
console.log(empty); //Set(0) {}
const nums = new Set([1,2,3,4,5])
console.log(nums); //Set(5) {1,2,3,4,5}
```
