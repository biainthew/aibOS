### MCP(Model Context Protocol) 란 ?

- **Model**: Claude 3.5 Sonnet, GPT-4o, Gemini 등 AI 프로그램의 본체를 말합니다.
- **Context**: 내 컴퓨터 파일, DB, 노트 등의 상황과 데이터 등의 작업 기억을 말합니다.

따라서 MCP 란 AI 에게 맥락을 규격화된 방식으로 전달해주는 규칙입니다.


### MCP 서버란?


MCP 서버는 쉽게 말해 AI가 외부(프로그램, 데이터베이스, API, 파일 시스템 등)와 소통할 수 있도록 연결해 주는 확장 플러그인 입니다.


Anthropic에서 발표한 오픈소스 표준 규격인 MCP 를 따르는 프로그램으로 AI가 안전하고 규격화된 방식으로 외부 도구를 가져다 쓸 수 있도록 도와주는 역할을 합니다.


### AI와의 관계

- **MCP 클라이언트 (Claude Code 등):** 도구와 데이터가 필요한 AI 주체
- **MCP 서버 (Notion, GitHub, Postgres 등):** 클라이언트에게 필요한 기능이나 데이터를 제공하는 프로그램

### MCP 서버를 연결하면 가능해지는 것들


기본적인 코드 수정을 넘어 다양한 외부 도구를 AI가 직접 제어할 수 있게 됩니다.

- **브라우저 자동화 (Playwright/Puppeteer MCP):** AI가 직접 브라우저를 띄워 웹사이트를 테스트하거나 스크린샷을 찍어 오류를 디버깅할 수 있습니다.
- **문서 및 협업 툴 연동 (Notion/Slack MCP):** 현재 프로젝트의 진행 상황을 AI가 알아서 노션 페이지에 정리하거나 슬랙으로 보고하게 할 수 있습니다.
- **데이터베이스 연동 (Postgres/MySQL MCP):** AI가 DB에 직접 연결하여 테이블 스키마를 읽고 쿼리를 날려 데이터가 잘 들어갔는지 검증할 수 있습니다.
