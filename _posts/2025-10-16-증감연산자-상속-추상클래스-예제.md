**문제 1.** 아래 연산의 출력값 ?


{% raw %}
```java
public class Test {
    public static void main(String[] args) {
        int x = 5;
        System.out.println(x++ + ++x);
    }
}
```
{% endraw %}


**해설 1.**

1. 초기값 `x=5`
2. `x++`은 후위 증가 연산자라서 초기값(5)을 먼저 사용하고 그 후 `x` 를 1 증가시킴

    => `x ++`는 5를 반환하고 이후 `x=6` 이 됨

3. `++x` 는 전위 증가 연산자라서 먼저 1 증가한 후 그 값을 사용

    => `++x` 실행 후 x=7이 되고 7이 반환됨


**문제2.** 아래 코드에서 오류가 발생하는 이유


{% raw %}
```java
abstract class Animal {
    abstract void makeSound();
}

class Dog extends Animal {
    void bark() {
        System.out.println("Woof!");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal myPet = new Dog();
        myPet.makeSound();
    }
}
```
{% endraw %}


**해설2.**


📌 **상속 (Inheritance)**


: 부모(상위) 클래스의 기능을 자식(하위) 클래스가 물려받아 사용할 수 있는 개념


: 코드 재사용성이 좋아지고 유지보수가 쉬워짐


**예제 코드**


{% raw %}
```java
// 부모 클래스
class Animal {
	String name;

	void eat() {
		System.out.println(name + "is eating.");
	}
}

// 자식 클래스 (Animal을 상속받음)
class Dog extends Animal {
	void bark() {
		System.out.println(name + "says Woof!");
	}
}

// 메인 실행 코드
public class InheritanceExample {
	public static void main(String[] args) {
		Dog myDog = new Dog();
		myDog.name = "Buddy"; // 부모 클래스의 필드 사용 가능
		myDog.eat(); // 부모 클래스의 메서드 사용 가능
		myDog.bark(); // 자식 클래스의 메서드 사용 가능
	}
}
```
{% endraw %}


**실행 결과**


{% raw %}
```java
Buddy is eating.
Buddy says Woof!
```
{% endraw %}


**정리**


`Dog` 클래스는 `Animal` 클래스를 상속받아서 `name, eat()`을 사용할 수 있음


추가로 `bark()` 메서드를 만들어 확장 가능


📌 **추상 클래스 (Abstract Class)**


: 공통적인 기능을 가진 부모 클래스지만 일부 메서드는 자식 클래스가 반드시 구현하도록 강제함


: 인스턴스를 직접 만들 수 없음(`new`로 객체 생성 불가능)


: `abstract` 키워드를 사용함


**예제 코드**


{% raw %}
```java
abstract class Animal {
	String name;

	// 일반 메서드 (구현 O)
	void eat() {
		System.out.println(name + " is eating.");
	}

	// 추상 메서드 (구현 x, 자식이 반드시 구현해야 함)
	abstract void makeSound();
}

class Dog extends Animal {
	// 추상 메서드 반드시 구현
	@Override
	void makeSound() {
		System.out.println(name + " says Woof!");
	}
}

// Main 클래스
public class AbstractExample {
	public static void main(String[] args) {
		Dog myDog = new Dog();
		myDog.name = "Charlie";
		myDog.eat();       // 부모 클래스의 구현된 메서드 사용
    myDog.makeSound(); // 자식 클래스에서 구현한 메서드 사용
	}
}
```
{% endraw %}


**실행 결과**


{% raw %}
```java
Charlie is eating.
Charlie says Woof!
```
{% endraw %}


**정리**


추상 클래스는 직접 객체 생성 불가, 공통 기능 제공


추상 메서드는 자식 클래스에서 반드시 구현해야 함


`Dog` 클래스가 `makeSound()` 메서드를 구현하지 않으면 컴파일 오류 발생
