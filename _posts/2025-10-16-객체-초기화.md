> 💡 **객체 초기화 ❓**  
> 클래스의 인스턴스를 생성하고 그 인스턴스를 사용할 준비를 하는 것  
>   
> 이를 통해  **변수에 실제 값을 할당**하거나 메모리 공간을 확보하고 그 **객체를 사용할 수 있게** 된다


### 객체 초기화 과정

1. 객체 생성

    객체를 초기화 하려면 먼저 클래스를 기반으로 새로운 인스턴스를 생성해야 한다


   {% raw %}
   ```java
   MyClass obj = new MyClass();
   ```
   {% endraw %}


    `MyClass` : **클래스**, 객체를 생성하기 위한 설계도 또는 템플릿


    `new MyClass()` : **인스턴스**, 클래스를 기반으로 객체를 생성하고 생성자를 호출해 초기화 작업을 수행


    `obj` : **참조 변수**, 클래스에서 만들어진 인스턴스를 참조


    > 💡 **객체와 인스턴스 차이** ❓  
    > 객체 > 인스턴스  
    >   
    > 어떤 데이터 타입이든 메모리에 할당되면 객체로 볼 수 있음  
    >   
    > 인스턴스는 특정 클래스에서 생성된 객체를 말함


    모든 인스턴스는 객체이지만 객체라는 용어는 더 일반적인 개념이고 인스턴스는 특정 클래스와 관련된 객체를 지칭할 때 사용

2. 필드 값 설정

    객체가 생성된 후 필드에 초기값을 설정할 수 있다


   {% raw %}
   ```java
   obj.name = "John";
   ```
   {% endraw %}


### 객체 초기화 예시

1. 클래스 정의

   {% raw %}
   ```java
   class Person {
   	String name;
   	int age;

   	// 생성자
   	Person(String name, int age) {
   		this.name = name; // 필드 초기화
   		this.age = age;
   	}

   	void introduce() {
   		System.out.println("안녕하세요, 저는 " + name + "이고, 나이는 " + age + "살입니다.");
   	}
   }
   ```
   {% endraw %}

    1. 객체 초기화

       {% raw %}
       ```java
       public class Main {
       	public static void main(String[] args) {
       		// Person 객체 초기화
       		Person person = new Person("Alice", 25); // 생성자를 통한 초기화
       		person.introduce(); // 출력: 안녕하세요, 저는 Alice이고, 나이는 25살입니다.
       	}
       }
       ```
       {% endraw %}


### 초기화의 종류

1. 기본 생성자를 이용

   {% raw %}
   ```java
   class MyClass {
       int value;

       // 기본 생성자
       MyClass() {
           value = 10; // 초기값 설정
       }
   }

   MyClass obj = new MyClass(); // 초기화
   ```
   {% endraw %}

2. 사용자 정의 생성자를 이용

   {% raw %}
   ```java
   class MyClass {
       int value;

       // 사용자 정의 생성자
       MyClass(int value) {
           this.value = value;
       }
   }

   MyClass obj = new MyClass(100); // 초기화
   ```
   {% endraw %}

3. 필드 초기화

   {% raw %}
   ```java
   class MyClass {
       int value = 10; // 필드 초기화
   }

   MyClass obj = new MyClass(); // 초기화
   ```
   {% endraw %}

4. 메서드를 통한 초기화

   {% raw %}
   ```java
   class MyClass {
       int value;

       void initValue(int value) {
           this.value = value;
       }
   }

   MyClass obj = new MyClass();
   obj.initValue(20); // 메서드를 통한 초기화
   ```
   {% endraw %}
